# 故障定位终端界面原型

## 项目概述

这是一个基于Qt框架开发的故障定位终端界面原型（MVP），主要用于电力系统或工业设备的故障监测、数据采集和波形分析。

## 核心功能

### 1. 串口通信
- 支持与设备的串口通信
- 支持真实串口连接和模拟模式（"SIM"模式）
- 可配置串口参数（端口、波特率）
- 支持命令发送和数据接收

### 2. 波形显示
- 支持多通道波形绘制
- 支持波形的缩放（放大/缩小）
- 支持波形的拖拽滑动
- 支持自动滚动显示最新数据

### 3. 故障信息管理
- 显示故障类型、发生时间、位置和持续时间
- 提供开始/停止监测功能
- 支持故障数据的导出（CSV格式）

### 4. 命令控制
- 支持手动发送命令
- 提供快捷命令按钮（读取状态、查询参数、开始/停止采集）
- 实时显示命令执行结果

## 技术架构

### 主要组件
- **MainWindow**：主窗口，负责整体布局和逻辑协调
- **WaveViewWidget**：波形显示控件，处理波形绘制和交互
- **SerialService**：串口服务，处理串口通信
- **ConsoleDock**：控制台，显示通信日志
- **FaultInfoWidget**：故障信息显示

### 数据流程
1. 串口接收设备数据
2. 解析数据格式（如"[RX] 2.00,4.00,2.00"）
3. 更新波形数据
4. 绘制波形显示
5. 记录通信日志

## 安装与运行

### 环境要求
- Qt 5.10 或更高版本
- C++11 或更高版本
- 支持 Windows、Linux 等平台

### 编译步骤
1. 克隆项目到本地
2. 使用 Qt Creator 打开 `NEW.pro` 文件
3. 构建项目
4. 运行应用程序

### 配置串口
- 首次运行时会提示配置串口参数
- 可选择真实串口设备或使用模拟模式（输入"SIM"）
- 波特率默认为 115200

## 使用方法

### 基本操作
1. **开始监测**：点击"开始"按钮，开始接收和显示数据
2. **停止监测**：点击"停止"按钮，停止接收数据并清空波形
3. **导出数据**：点击"导出"按钮，将波形数据导出为CSV格式

### 波形操作
- **放大**：点击"Zoom In"按钮或使用鼠标滚轮
- **缩小**：点击"Zoom Out"按钮或使用鼠标滚轮
- **复位**：点击"Reset"按钮，回到默认视图
- **拖拽**：鼠标拖动波形可查看历史数据

### 命令发送
- 在命令输入框中输入命令，按回车或点击"发送"按钮
- 点击快捷命令按钮发送常用命令

## 数据格式

### 接收数据格式
设备发送的数据格式应为：
```
[RX] 数值1,数值2,数值3
```
例如：
```
[RX] 2.00,4.00,2.00
```

### 导出数据格式
导出的CSV文件格式为：
```
index,value
0,0.00
1,0.03
...
```

## 模拟模式

当串口设置为"SIM"时，系统进入模拟模式：
- 模拟设备连接成功
- 可发送命令并接收模拟响应
- 用于测试界面功能

## 技术亮点

1. **模块化设计**：各功能组件独立封装，便于维护和扩展
2. **多通道波形**：支持同时显示多条波形数据
3. **灵活的串口配置**：支持多种波特率和串口设备
4. **用户友好的交互**：支持波形缩放、拖拽等操作
5. **模拟模式**：无需真实设备即可进行界面测试

## 应用场景

1. **电力系统故障定位**：监测电网故障，显示故障波形，辅助定位故障点
2. **工业设备监测**：实时监测设备运行状态，分析异常波形
3. **数据采集分析**：采集传感器数据，进行波形分析和数据导出
4. **嵌入式设备调试**：与嵌入式设备通信，发送命令并查看响应
